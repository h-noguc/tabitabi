# 0003 Web で出し、本格運用でネイティブ化する

状態: 決定（2026-10-26）
判断者: 自分
議論: https://claude.ai/code/session_01RRsWb1PMfgKNATkiZKYMQQ

## 決定
最初はデプロイが簡単な Web アプリ（PWA 想定）にする。本格運用に入る時点で、使い勝手と安定性のためにネイティブアプリにする。

## 理由
- まず2人で使い始めて要件を確かめることを優先する
- ネイティブ化で得たいもの: 共有シートからの登録（iOS の PWA は共有先になれない）、安定した位置情報、オフライン時の扱い

## 影響
- API は画面から独立した契約として作り、ネイティブ版でも使う
- 判定ロジック・型は Web とネイティブで共有できる場所に置く

## 次に必要になる条件
ネイティブ化の着手時に、バンドルID・製品名・オフライン対応（local-first の要否）を判断する。
