# 0006 API の境界は持つ、中核は薄く

状態: 提案
判断者: 自分
議論: https://claude.ai/code/session_01RRsWb1PMfgKNATkiZKYMQQ

## 決定（案）
- 画面は必ず API（Hono + Zod）を通して DB に触れる
- 中核（純粋関数）に置くのは、実際の業務ルールだけ:
  - want↔been の遷移と訪問記録
  - グループのメンバーか、誰が消せるかなどの権限判定
  - 同じ場所かの判定（外部ID、近い座標と似た名前）
  - Maps URLs の組み立て
- 一覧・編集などの CRUD は API から Drizzle で直接 DB に通す
- 依存方向の自動検査は、違反が繰り返されるまで入れない
- Hono が API と Vite のビルド成果物を両方配信し、デプロイは1つにする
