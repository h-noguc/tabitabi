# 0004 OSS・一般公開は出口であって目的にしない

状態: 決定（2026-10-26）
判断者: 自分
議論: https://claude.ai/code/session_01RRsWb1PMfgKNATkiZKYMQQ

## 決定
OSS 化・一般公開は将来の選択肢として残すが、2人の用途を優先し、そのための機能は作らない。

## 出口を閉ざさないための約束
- 秘密情報・実データを git 履歴に一度も入れない（テストは架空の値）
- 外部サービスの規約・ライセンスで、公開時に問題になる依存を避ける
- 共有は「2人」ではなく「グループ」で表す。ただし招待 UI などは作らない
- 開発セッションのログはアプリのレポ・DBに入れない（論点6）
