# 0005 正本は独自DB、Google マップとはリンクで共存する

状態: 決定（2026-10-26）
判断者: 自分
議論: https://claude.ai/code/session_01RRsWb1PMfgKNATkiZKYMQQ

## 決定
- 場所・状態（want/been）・メモ・訪問記録の正本は独自DB
- Google マップからのデータ取得はしない。登録はアプリ内で行う
- 経路・ナビは公式の Maps URLs（APIキー不要）で Google マップを開く

## 役割分担
| 役割 | 担当 |
|---|---|
| 行きたい・行った・メモ・訪問記録・追加者 | 独自DB |
| 経路・ナビ・営業時間・口コミ | Google マップを開く |
| 外部の場所との対応 | 外部ID（Google place_id、OSM ID など）を参照として保存 |

## 登録方法の候補
- A. アプリ内検索から選ぶ（主）
- B. 他アプリからの共有。店名・住所を受け取り、アプリ内で検索し直す。短縮URLの解析は常用しない
- C. 地図のピン・現在地（主）
- D. 既存 Maps リストの一回限りの取り込み

## 注意
Google Places API 由来のデータは、規約上 place_id 以外の保存に期間制限がある（緯度経度など）。Google のデータを地図に出すなら Google の地図を使う条件もあるはず。どちらも採用前に最新規約で確認する（論点3）。
